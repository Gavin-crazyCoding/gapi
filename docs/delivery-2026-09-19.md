## 1. 交付范围

gapi 是面向终端用户的 LLM 网关：注册登录、签发 `gapi-` 前缀 API Key、代理转发到
FreeLLM API（:3001）、按 GavinCoin（◎）计量扣费。FastAPI + SQLite + 零构建前端，
单实例运行于 :3002。

  计费倍率、per-key 用量、多设备指纹集合、汉堡导航、亮暗主题、每日签到。

## 2. 功能清单

### 2.1 用户侧

| 能力 | 说明 |
|---|---|
| 注册/登录 | JWT（7 天）+ HttpOnly SameSite=Strict Cookie；注册即返回 JWT 直接进面板；首个注册用户自动 admin；登录自动触发每日签到 |
| 每日签到 | 24h 滚动窗口；`BEGIN IMMEDIATE` 条件 UPDATE 防双领；面板加载自动调用，无需重复登录；余额受 `max_coin_per_user` 封顶 |
| API Key | SHA-256 哈希存储，明文仅创建时返回一次；`expires_at` 强制；列表带 30 天用量 |
| 试验场 | 面板内直接试模型，走完整代理+计费管线 |
| 模型目录 | 每 300s 拉取上游 `/v1/models`（single-flight + 失败回退旧缓存），按 gapi 定价联表展示 |
| 计费 | 预扣 → 结算 → 退款；按上游 `X-Routed-Via` 实际路由模型重定价；上游失败全退；断流按已产生 token 结算 |
| 代币包 | 订阅式配额（FIFO 扣减、过期清零）；购包汇率 `coin_rate` |
| 兑换码 | `GAVI-XXXX-XXXX-XXXX`；每用户一次、max_uses 上限、原子防超兑 |
| 公告 | 用户登录弹窗（一次），admin CRUD + 时间窗口 + is_active 开关 |
| 路由策略 | auto/fastest/smart/balanced/stable 五档，随用户存储 |

### 2.2 安全机制

| 机制 | 说明 |
|---|---|
| 指纹绑定 | 每账号 ≤5 个设备（LRU 驱逐）；登录自动登记；面板数据 API 严格校验（缺失/不匹配 403）；CLI/admin 面板可解绑 |
| 管理员菜单三层防线 | ① HTML 默认 `hidden`（慢网/JSError 不泄露）② JS 点击守卫（`isAdminUser`）③ 服务端 `get_admin_user` 403（真正闸门） |
| 限流 | 登录 30 次/5 分钟/IP、注册 20 次/小时/IP、重发验证 3 次/小时/账号 |
| 错误契约 | gapi 自身错误统一 `{"error":{code,message}}` + `X-Gapi-Error: 1`；上游错误原样透传不加该头 |
| 面板下发 | `/panel` 与资产均需会话；allow-list 防路径穿越；CSP 严格（script-src 'self'、无 inline script） |
| 会话 | HttpOnly Cookie（XSS 不可读）；SameSite=Strict（防 CSRF）；生产 HTTPS 自动 Secure |

### 2.3 管理侧（固定三入口）

| 入口 | 职责 |
|---|---|
| `manage.py` CLI | coin grant/balance/history；user list/activate/deactivate/fingerprints/clear-fingerprint；pricing set/list/seed/sync；usage user；code create/list/deactivate |
| `/admin/*`（面板） | 经济参数（settings）、公告 CRUD、全局统计（stats） |
| `/users/*`（面板） | 用户 CRUD、充值、解绑指纹、删除（唯一 admin 保护） |

经济参数优先级：**DB 行 > .env > 硬编码**；60s TTL 缓存，写入即失效；
改 `.env` 需重启进程。

## 3. 计费模型

```
按量：cost = tokens/1000 × 模型费率(in/out 分开) × rate_multiplier
媒体：cost = 端点基础价(images ◎0.05 / videos ◎0.5 / audio ◎0.02) × rate_multiplier
```

- 三个价格杠杆作用域不同：模型定价表（per-1k 基础费率）/ `rate_multiplier`
  （按量计费整体缩放）/ `coin_rate`（仅购包兑换比）。改文案时勿混淆。
- 未定价模型回退 gpt-4o 费率（宁可多收不免费）。
- 每笔余额变动都落 `credit_transactions` 账本（tx_type：reserve/settle/grant/adjust/
  package_purchase/daily_login/signup_bonus/redeem）。

## 5. 部署清单

```bash
pip install -e '.[dev]'
cp .env.example .env          # 必填 FREELLM_API_KEY、GAPI_JWT_SECRET（生产换长随机串）
alembic upgrade head          # head = c3d4e5f6a7b8
python manage.py pricing seed
uvicorn app.main:app --port 3002
```

- 数据库自动建于 `data/gapi.db`（WAL，busy_timeout=5000），与上游库完全隔离。
- 改 `.env` 需重启进程；面板改经济参数立即生效。
- 静态资产带 `?v=` 版本串（当前 `20260919a`），改前端时整体升档防缓存错位。

## 6. 已知边界（有意为之）

- gapi 侧无请求体大小上限（upstream 有 25MB）。
- `settle` 允许超出预扣的追加扣款（余额可为负），优先保服务可用。
- `ApiKey.quota` 列已存储但无消耗语义（语义未定义前不实现）。
- 限流/设置缓存为进程内存态：多实例部署需替换为共享后端（当前单实例架构）。

## 7. 本阶段修复清单（2026-09-19）

| 问题 | 根因 | 修复 |
|---|---|---|
| 慢网络下普通用户看到完整管理员菜单并可点开 | `panel.html` 中 admin nav 按钮默认可见，JS 在 `/auth/me` 返回后才隐藏；慢网/JSError 时隐藏逻辑不执行 | HTML 默认 `hidden` + `/auth/me` 确认角色后显示 + `isAdminUser` 点击守卫（三层防线，服务端 403 兜底） |
| 登录后指纹绑定偶发丢失 | `award_daily_bonus` 开头的 `db.rollback()` 把刚写入的指纹绑定一起回滚 | 指纹绑定先 `db.commit()`，再做签到 |
| 签到接口 naive/aware datetime 比较 TypeError | SQLite 存 naive 字符串，代码用 aware UTC 比较 | 全链路 naive UTC |
| 每日签到需退出重登才能领 | 奖励只在 `/auth/login` 发放 | 新增 `POST /user/checkin`，面板 boot 自动调用 |

## 8. 运维备忘

- **用户被指纹锁定**：`python manage.py user clear-fingerprint <email>` 或 admin 面板
  「解绑指纹」。
- **充值/扣款**：`python manage.py coin grant <email> <amount> [--note]`（负数为扣）。
- **定价**：`pricing set/list/seed/sync`；未定价模型按 gpt-4o 费率回退。
- **缓存**：settings/pricing 60s TTL；写入即失效；`.env` 改动需重启。
- **前端改动**：升 `?v=` 版本串（`grep -rn "20260919a" web/` 定位全部位置）。
